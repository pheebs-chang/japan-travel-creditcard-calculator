# 馬克金融科技 2026 知識圖譜

來源：markreadfintech.com 2026-01-01 至 2026-11-01 共 126 篇文章全文，由 AI 分批抽取概念、實體、事實、關係與政策事件。

## 內容
- `knowledge-graph.html`：互動頁面（需連網載入 3d-force-graph）。四個視圖：
  - 三維關係圖：文章 → 段落 → 節點三層，一段原文連到它提到的所有節點。
  - 產業鏈 × 地區：依傳統金融上下游（監理與政策、金融基礎設施、資金中介、通路與應用、周邊）× 台灣／亞洲／歐盟／美國／英國／其他國外／跨國。
  - 區塊鏈：區塊鏈技術本身 vs 鏈上金融。
  - 政策時間軸：各地區的法條法案、政策、監理方向。
  - 段落查閱：用文章、地區、議題、產業鏈、區塊鏈、節點交叉篩選每一段原文的標記，附逐篇核對報告。
- `obsidian-vault/`：用 Obsidian 開啟此資料夾。
  - `概念/`、`實體/`：每個節點一則筆記，屬性欄有 region、entity_type、layer、sector、blockchain，內含雙向關係、相關政策事件、事實與出處。
  - `文章/`：逐段標記。每段一行：原文開頭、階層標籤（`#地區/台灣`、`#議題/穩定幣`、`#產業鏈/中游/商業銀行`、`#區塊鏈/鏈上金融`、`#政策`）、連到的節點，以及段落錨點 `^pN`。
  - `00 逐篇核對報告.md`：每篇的段數、已標記段數與有節點的段數。
  - `索引/`：地區、產業鏈、區塊鏈、各地區政策時間軸。
- `kg.json`：全部資料。
